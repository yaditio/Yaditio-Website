# BIM-BAM

**BIM-BAM** (Building Information Modeling - Building Automation Management) is an automation toolkit designed for AEC (Architecture, Engineering & Construction) workflows.

## Key Features

- **Automated Workflow**: Integrates design data and automates model generation/processing.
- **Data Extraction**: Extracts spatial, structural, and quantity data directly from models.
- **Interoperability**: Connects Python scripts with industry BIM platforms.
